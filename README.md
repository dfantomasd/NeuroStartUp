# NeuroStartUp

NeuroStartUp — учебный проект по изучению Git и GitHub.

## О проекте

Этот репозиторий создан в рамках домашнего задания
«Работа с удалённым репозиторием».

Здесь мы научимся:
- Работать с Git.
- Публиковать проекты на GitHub.
- Создавать новые ветки.
- Объединять изменения из разных веток.
